# Coverage fixture

Original synthetic GeoJSON under the project MIT license. These shapes are not surveyed real-world features.
The fixture exercises a forest polygon with a hole, water/building exclusions, a buffered road, and a tree outside
forest coverage. It is shared by offline correctness tests and tests/procedural2-coverage.earth.

The live demo, tests/procedural2-osm.earth, uses the separate OSM FeatureSource from tests/osm.earth instead.
